# OASIS Master Branding Package

**The permanent, single source of truth for OASIS branding.** Built and
verified during Module 3D (Branding & UI Identity). Start with
`Brand-Guidelines/Brand-Identity.md`.

## Contents

```
Branding/
├── Logos/                         Primary, Compact, Monochrome, Icon logo files
│   ├── OASIS-Logo-Light.png        Full lockup (icon+wordmark+tagline+full name), light bg
│   ├── OASIS-Logo-Dark.png         Full lockup, dark bg
│   ├── OASIS-Logo-Monochrome.png   Single-color lockup (composed — see Logo-Usage.md §7)
│   ├── OASIS-Compact-Light.png     Icon+wordmark only, light bg
│   ├── OASIS-Compact-Dark.png      Icon+wordmark only, dark bg
│   ├── OASIS-Icon.png              Icon mark alone, square
│   └── Extras/                     Additional real monochrome/single-color variants
├── Favicons/                       favicon.ico, favicon-16/32.png, apple-touch-icon, android-192/512
├── Social/                         Profile-Picture, Cover-Image, LinkedIn-Banner
└── Brand-Guidelines/
    ├── Brand-Identity.md           Name, tagline, package overview — START HERE
    ├── Color-Palette.md            Official colors + computed WCAG contrast data
    ├── Typography.md               Official typefaces and usage
    ├── Logo-Usage.md               Primary/Secondary/Icon usage, do's & don'ts, full asset provenance
    └── Spacing-Guidelines.md       Minimum size, clear space, product spacing conventions
```

## No SVG files

The uploaded source material was raster (PNG) brand-board images only —
no vector files were ever supplied. See `Brand-Identity.md §2` for why
one wasn't auto-generated, and what to do if real vector source becomes
available later.

## Every asset's origin is disclosed

`Logo-Usage.md §7` lists every single file and states plainly whether it's
a direct crop, a mechanical resize, or a composition of real, unaltered
pieces — nothing in this package was artistically redrawn or recolored
from the original Branding Package.
