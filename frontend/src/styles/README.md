# styles/

Tailwind CSS is configured via `src/app/globals.css` (Tailwind v4's
CSS-first config — see that file, not a `tailwind.config.js`) and is the
default styling approach for OASIS per docs/01-srs-and-requirements.md.

This folder is reserved for anything that doesn't fit Tailwind utility
classes (e.g. print stylesheets, third-party widget CSS overrides) —
empty until a concrete need arises.
